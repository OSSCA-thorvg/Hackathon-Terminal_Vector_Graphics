🚀 TermVG

ThorVG 기반 터미널 벡터 그래픽 플레이어

설치 및 실행

npm 패키지를 다운로드하고 모든 기능을 경험해 보세요.

npm i -g termvg termvg

터미널 단축키

  • Space 재생/일시정지
  • M 렌더링 모드
  • ←/→ 프레임 이동
  • D 다크모드 반전
  • ↑/↓ 파일 탐색
  • Enter 파일 로드
  • L Lottie MCP 온라인 에셋 검색
    * 터미널의 QR코드를 스마트폰으로 스캔 후, 리다이렉트된 주소창의 code 파라미터 값을 입력하여 연동합니다.
⚠️ 웹 데모 제약 안내
현재 브라우저 데모(WASM)에서는 로컬 파일 탐색과 온라인 검색 기능이 제한됩니다.
모든 기능은 터미널에 직접 패키지를 설치하여 이용해 주세요.
