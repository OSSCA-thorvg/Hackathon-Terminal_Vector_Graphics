✨ 핵심 기능

⚡

WASM 네이티브 성능

ThorVG C++ 엔진을 WebAssembly로 컴파일하여 30fps 실시간 렌더링

🎨

3가지 렌더링 모드

Half-block, Quadrant, Braille 문자로 터미널 해상도 극대화

🔍

실시간 파일 검색

로컬 폴더 스캔 + 실시간 필터링으로 빠른 파일 탐색

🌐

LottieFiles MCP

OAuth 2.0 + QR 인증으로 온라인 에셋 검색/다운로드/즉시 재생

🖥️

웹 터미널

ttyd 연동으로 브라우저에서도 동일한 CLI 경험 제공

🛡️

더블 버퍼링

Synchronized Output Mode로 애니메이션 깜빡임 완전 제거
