📖 사용 가이드

🗂 파일 탐색

  • O폴더 경로 열기
  • ↑↓파일 탐색
  • ←→페이지 넘기기
  • S파일 검색
  • Enter파일 선택/재생

▶ 재생 제어

  • Space재생/일시정지
  • ←→프레임 시크 (정지 중)

🎨 렌더링

  • M렌더 모드 전환
  • D다크 모드 전환
  • HB Half-block (1×2)
  • QD Quadrant (2×2)
  • BR Braille (2×4)

🌐 LottieFiles

  • LLottieFiles 검색
  • ESC검색 취소

ℹ️ About

TermVG는 ThorVG C++ 엔진을 WebAssembly로 컴파일하여 터미널에서 Lottie/SVG를 30fps로 실시간 렌더링하는 플레이어입니다.
